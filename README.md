# LINE AI Reply

LINE公式アカウントにテキストを送ると、OpenAIの回答を返す最小のボットです。
Node.js 22以上で動きます。外部パッケージ・データベースは不要です。

## 1. 用意するもの

- LINE公式アカウントと、そのアカウントのMessaging APIチャネル
- OpenAI APIキー（ChatGPTの月額契約とは別にAPIの利用料金がかかります）
- Node.js 22以上が動く、公開HTTPS URLを持つホスティング先

LINE公式アカウントがない場合は作成し、LINE Official Account Managerの設定からMessaging APIを有効にしてください。その後LINE Developersで対象チャネルを開きます。

## 2. キーを設定する

プロジェクトのフォルダで実行します。

```sh
cp .env.example .env
```

`.env` をエディタで開き、次の3項目を入力してください。

| 設定名 | 入力するもの |
| --- | --- |
| `LINE_CHANNEL_SECRET` | LINE Developersの対象チャネル → チャネル基本設定 → チャネルシークレット |
| `LINE_CHANNEL_ACCESS_TOKEN` | 同じチャネルのMessaging API設定 → チャネルアクセストークン |
| `OPENAI_API_KEY` | OpenAIのAPI管理画面で発行したAPIキー |

`OPENAI_MODEL` は初期値の `gpt-4.1-mini` のままで始められます。利用できない場合は自分のOpenAIプロジェクトで利用可能なモデルに変更します。

`.env` はGitの管理対象から除外しています。キーをコードやチャットに貼らないでください。ホスティング先ではサービスの環境変数・シークレット設定に登録します。

## 3. 起動・テスト

```sh
npm test
npm start
```

依存パッケージがないため `npm install` は不要です。テストは外部APIを模擬するため、キーも料金も不要です。
起動後、別のターミナルで次を実行し、`LINE AI Reply is running` が返ることを確認します。

```sh
curl http://localhost:3000/
```

## 4. 公開してLINEに接続する

1. プロジェクトをNode.jsとHTTPSに対応するホスティングサービスへ配置します。
2. 上記3つのキーを環境変数に登録し、起動コマンドを `node server.js` にします。`PORT` はサービスが指定する値を利用し、指定がなければ3000です。
3. LINE DevelopersのMessaging API設定で、Webhook URLに `https://あなたの公開ドメイン/webhook` を登録します。
4. 「検証」が成功したら「Webhookの利用」をオンにします。
5. LINE Official Account Managerで「応答メッセージ」をオフにし、二重返信を防ぎます。
6. 公式アカウントを友だち追加し、「こんにちは」と送って返信を確認します。

`localhost` はLINEからアクセスできません。公開HTTPS URLが必要です。このコードを作成しただけでは公開・実アカウントとの接続は完了しません。

## この最小版の仕様

- 1通ごとに回答します。過去の会話は引き継ぎません。
- 画像・音声にはテキスト送信をお願いする返信を返します。
- LINEの署名を検証し、不正なWebhookを拒否します。
- 会話本文やキーをログに出さず、OpenAIには `store: false` を指定します。ただし外部サービス側のデータ取り扱い規定は適用されます。
- LINEのテキストをOpenAIに送ることを利用者に案内してください。
- 再配信イベントは処理しません。キュー・自動再試行はなく、障害時に返信できないことがあります。
- 少人数で試すための構成です。一般公開前には利用者制限や利用回数制限を追加してください。OpenAIの利用額も管理画面で確認してください。

## 返信が来ないとき

- 起動時に不足する設定名が表示される → `.env` またはホスティング先の環境変数を確認します。
- Webhook検証が失敗する → 公開URL、`/webhook`、サーバーの起動状態、チャネルシークレットを確認します。
- 「現在回答できません」と返る → OpenAIのAPIキー、課金設定、利用上限、モデル名を確認します。
- LINEへの返信が失敗する → 同じチャネルのアクセストークンを使っているか確認します。
